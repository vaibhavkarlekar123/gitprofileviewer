# gitprofileviewer

i created this project called git profile viewer by using following API

1.https://api.github.com/users?per_page=${count}
2.https://api.github.com/users/taylorotwell
3.https://api.github.com/users?since=6000&per_page=20

-->first one is used for to show the random github profiles
-->i used this second API..which shows you the github profile that you want to see
-->third one also similar to the first one

# always remember about the limit of the api calls
